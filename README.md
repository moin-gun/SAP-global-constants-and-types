# SAP-global-constants-and-types
---
Download the file `main.txt` and open in any text editor (preferably Notepad++) and use Ctrl+F to type the value you're looking for.
<br>e.g. If you're looking for a constant with value 'A' then you need to type `'A'`(along with single quotes) and hit enter. You will get constant `wmegc_huplan` that you can directly reuse in any program, class or FM without defining it anywhere.

One should permanently bookmark this repo because these constants are given by SAP universally and work in every SAP GUI on the Earth!<br>Stay tuned for OO constants from the table `SEOCOMPODF`
